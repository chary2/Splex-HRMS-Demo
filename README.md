# HRMS Employee Portal

Angular 20 + Bootstrap 5 responsive Employee Login and Dashboard template.

## Included

- HRMS Employee Login
- Password show/hide
- Responsive login layout
- Employee Dashboard
- Responsive sidebar
- Employee profile summary
- Attendance summary
- Leave balance
- Payroll/payslip summary
- Quick actions
- Recent leave requests
- Upcoming holidays
- Demo login navigation

## Run

Install Node.js LTS, then:

```bash
npm install
npm start
```

Open:

http://localhost:4200

Demo login:
Any non-empty email and password will navigate to the dashboard.

## Important

The login is a UI/demo implementation only. Replace the login method with your real authentication API, token/session handling, route guards, and backend authorization before using it in production.
